# Enablement Assets

Everything another SA needs to pitch and run the StoreSight IQ demo.

| Asset | What it is | Where |
|---|---|---|
| **Pitch deck** | 2-slide framing deck — the problem ("multi-site operators are flying blind") and StoreSight IQ's three capabilities. Open in a browser; arrow keys / `F` for full-screen. | [`storesight-iq-pitch-deck.html`](storesight-iq-pitch-deck.html) |
| **Demo script** | Tell → show → tell playbook: use the deck to frame, walk the app, then recap. Framework + cues, not a rigid script. | [`demo-script.md`](demo-script.md) |
| **Demo video** | End-to-end recording of the demo flow, for your own prep. | [Google Drive](https://drive.google.com/file/d/1xrzniM71WO5pqKISektULx_hUsZV5Q0U/view?usp=sharing) |

## Demo video — reference only

> ⚠️ The linked recording was captured on an **earlier customer-specific build**
> and is a **reference for SAs to learn the flow** — **do not show it directly to a
> customer**. For a customer, stand up a fresh, re-skinned instance of this
> accelerator (an afternoon — see the repo `README.md`) and demo it live.

## How to use these together

1. **Deploy** the demo — repo [`README.md`](../README.md) +
   [`accelerator/WORKSPACE_STEPS.md`](../accelerator/WORKSPACE_STEPS.md).
2. **Prep** — watch the demo video once, then read [`demo-script.md`](demo-script.md).
3. **Pitch** — open the deck, run the tell → show → tell flow, land the recap.
